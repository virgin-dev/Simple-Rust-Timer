# Таймер с горячими клавишами

Простое приложение-таймер с поддержкой глобальных горячих клавиш. Таймер можно запустить с помощью горячей клавиши (по умолчанию F1) или кнопки в интерфейсе. Приложение всегда остается поверх других окон.

## Особенности
- Запуск таймера по горячей клавише (F1, F2, F3).
- Отображение оставшегося времени крупным шрифтом.
- Окно всегда поверх других окон.
- Простой и интуитивно понятный интерфейс.

## Установка

1. Убедитесь, что у вас установлен [Rust](https://www.rust-lang.org/).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/ваш-репозиторий.git
   cd ваш-репозиторий
   cargo build --release
   cargo run --release
## Использование
* Нажмите F1 (или другую выбранную клавишу) для запуска таймера.

* Таймер начнет отсчет с 10 секунд и отобразит оставшееся время в окне.

* Окно всегда остается поверх других окон (можно отключить в настройках).

## Зависимости
- [eframe](https://github.com/emilk/egui/tree/master/crates/eframe) — для создания GUI.

- [global-hotkey](https://github.com/obv-mikhail/global-hotkey) — для обработки глобальных горячих клавиш.
